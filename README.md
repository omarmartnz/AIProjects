# AIProjects

Colección de proyectos relacionados con Inteligencia Artificial.

## Contenido

Este repositorio reúne distintos proyectos, experimentos y utilidades relacionados con IA (machine learning, deep learning, LLMs, automatización, etc.).

## Estructura

Cada proyecto vive en su propia carpeta dentro de este repositorio, con su propio README describiendo su propósito, instalación y uso.
